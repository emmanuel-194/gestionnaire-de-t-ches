(Gestionnaire de tâches) - Jetpack Compose

Application Android réalisée dans le cadre de l'apprentissage des bases de **Jetpack Compose** (Android Basics with Compose).

## 🎨 Caractéristiques de l'interface
Le design respecte les spécifications UI suivantes :
1. **Centrage global** : L'ensemble du contenu (Image et Textes) est parfaitement centré verticalement et horizontalement sur l'écran.
2. **Illustration d'accomplissement** : Une image de validation (`ic_task_completed.png`) est positionnée en haut.
3. **Titre principal ("All tasks completed")** :
   - Style de police : Gras (`FontWeight.Bold`)
   - Marge supérieure (Padding Top) : `24dp`
   - Marge inférieure (Padding Bottom) : `8dp`
4. **Message secondaire ("Nice work!")** :
   - Taille de police : `16sp`
   - 
## 🛠️ Technologies & Outils
* **Langage** : [Kotlin](https://kotlinlang.org/)
* **Framework UI** : [Jetpack Compose](https://developer.android.com/jetpack/compose) (Material 3)
* **IDE** : [Android Studio](https://developer.android.com/studio)
* **Min SDK** : 21+
